## Project Overview
This project explores customer churn using a Telco customer dataset and a Power BI report. The goal is to understand customer characteristics and service/contract patterns that may be associated with churn.

## Files Included
- `Customer-Churn-Analysis.pbix` — Power BI report file. Open it with Microsoft Power BI Desktop.
- `telco_churn_unclean.csv` — raw/unclean input dataset used for analysis.

## Dataset Fields
The dataset includes customer profile details, tenure, subscribed services, contract and payment information, monthly and total charges, and the churn label.

## How to Use
1. Download the `.pbix` and `.csv` files from this repository.
2. Open `Customer-Churn-Analysis.pbix` in Power BI Desktop.
3. If Power BI asks for the data source path, point it to `telco_churn_unclean.csv` in the downloaded project folder.
4. Use the report pages and visuals to explore churn patterns.

## Tools
- Microsoft Power BI Desktop
- CSV dataset
